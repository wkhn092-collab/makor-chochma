# תסריט הדרכה (Loom) — מנהל האתר (אבישי)

האתר הוא **לידים**, לא חנות. אין מלאי/מחיר/הזמנות באתר.

## 1. סקירת האתר החי
- **[עכבר]** גלילה במובייל 375px: Hero → אודות → למה אצלנו → שירותים → המלצות → טופס  
- **הקראה:** «זה משפך אמון: קודם מי הסופר, אחר כך שיחה.»

## 2. בחירת עניין + וואטסאפ
- **[עכבר]** לחיצה על תפילין → סימון → פתיחת וואטסאפ עם prefill  
- **הקראה:** «העניין נשמר גם לטופס. אפשר לסמן גם נושא משני.»

## 3. שליחת ליד
- **[עכבר]** מילוי שם+טלפון → שליחה  
- **הקראה:** «הליד מגיע למייל הרב + עותק אליך, ונשמר ב־Sanity אם מוגדר.»

## 4. Sanity לידים (אם מחובר)
- **[עכבר]** Studio → מסמכי Lead → סטטוס חדש/נוצר קשר  
- **הקראה:** «רק אתה נכנס ל־Studio. MFA דלוק. לא משתפים טוקן.»

## 5. החלפת תמונות
- **[עכבר]** הצגת תג «הדמיה»  
- **הקראה:** «כשהרב שולח צילומים אמיתיים — מחליפים ב־`public/images` ומעדכנים `images.ts`.»
