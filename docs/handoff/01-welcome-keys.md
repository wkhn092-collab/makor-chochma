# המפתחות לאתר — מכון מקור חכמה

שלום,

האתר של **מכון מקור חכמה** מוכן כמערכת לידים פרימיום: עברית RTL, וואטסאפ וטלפון, טופס מאובטח, ומשפך ברור — שיחה → פגישה באלעד → סגירה פנים־אל־פנים (בלי סליקה באתר).

## כניסות

| מערכת | למי | הערה |
|---|---|---|
| האתר החי | כולם | URL יועדכן אחרי דומיין |
| Vercel | אבישי | Deploy + env |
| Sanity (לידים) | אבישי בלבד | MFA חובה |
| Resend / Cloudflare | אבישי | מפתחות ב־Vercel בלבד |

הרב **אינו** עורך תוכן ב־CMS — עדכונים דרך אבישי בפריסה.

## SLA (גבולות)

**כלול בתחזוקה (ריטיינר):** באגים, עדכוני אבטחה, ניטור בסיסי, תיקון לידים/מייל, החלפת תמונות כשמסופקות.

**לא כלול (פיתוח נוסף):** עמודים חדשים, סליקה, חנות, שפה שלישית, אינטגרציות חדשות.

## אבטחה

האתר עבר הקשחת AppSec ללידים: Turnstile, honeypot, Zod, Origin check, rate limit, כותרות אבטחה, CSP Report-Only, `/api/health`.  
**חובה:** 2FA על כל חשבון (Vercel, GitHub, Sanity, Cloudflare, Resend) — אל תשתפו סיסמאות או טוקנים בוואטסאפ.
